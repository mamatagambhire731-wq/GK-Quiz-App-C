General Knowledge Quiz Application (C)

Mini Project

This is a simple General Knowledge Quiz Application developed using the C programming language.

Features

- Multiple-choice questions.
- Calculates final score.
- Displays correct answers.
- Beginner-friendly program.

Technology Used

- C Language
- Cxxdroid (Android)
- GitHub

How to Run

1. Open "quiz.c" in Cxxdroid.
2. Compile and run the program.
3. Enter the option (a, b, c, or d).
4. View your final score.
